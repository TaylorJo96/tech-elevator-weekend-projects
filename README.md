# Tech Elevator Weekend Projects

Every week at Tech Elevator (2022), we had a weekend pair-programming project
that started Friday and was due Monday morning. These are the projects my
partners and I completed, showing how my skills grew week by week, from
command-line basics to databases, REST APIs and front-end web development.

| Week | Project | What it covers |
|---|---|---|
| 1 | [Command-Line Programs](week-01-command-line-programs) | Decimal → binary converter and Fibonacci sequence: loops, arrays, user input |
| 2 | [TEams](week-02-teams-project-management) | Project-management model: classes, encapsulation, collections |
| 3 | [Pet Elevator CRM](week-03-pet-elevator-crm) | Inheritance, interfaces and polymorphism, with 12 MSTest unit tests |
| 6 | [Campground Reservations](week-06-campground-reservations) | SQL Server, DAO pattern, data-access integration tests |
| 7 | [Cat Cards API](week-07-cat-cards-api) | ASP.NET Core CRUD REST API that consumes an external API and stores data in SQL Server |
| 9 | [TE Popsicles Website](week-09-popsicles-website) | Responsive HTML/CSS (CSS Grid, media queries) built from desktop and mobile mockups |

**Tech:** C# · .NET Core 3.1 · MSTest · SQL Server · ASP.NET Core · HTML · CSS

Each folder includes the original Tech Elevator assignment README.
